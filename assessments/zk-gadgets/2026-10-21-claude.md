### 1. Orientation: strong

The probe answered all four questions correctly in about 6 minutes, reading `AGENTS.md`,
`README.md`, `DISCOVERY.md`, `discover/frontier.json`, the ledger, the priority log and
the trial report, and running the picker.

- **Problem:** prove the same BN254 R1CS statements with fewer constraints and less
  prover work, without opening soundness loopholes, against pinned arkworks baselines.
- **Current result:** author-checked candidate records, not accepted: 192 → 64 rows for
  64 difference-of-squares expressions, 10 → 4 for x<13, 65 → 64 for a 64-bit range
  predicate, 2182 → 2174 for a depth-8 Merkle ordering; known techniques, not novelty
  or optimality claims. It named what's pending: review of the custom checker, numerical
  checks only on ten baseline cases, exploratory timings.
- **Where help is wanted:** verification first (35: try to evade the checker), then
  compositions (30), range encodings (25), baseline audit (10).
- **How to contribute:** the Handoffs thread, a `research/<name>/` package and one
  focused PR, with what it must contain, and what stays with the maintainer.

Stale text it noticed: `research/trial/REPORT.md` has a Historical banner, but
`README.md` sends newcomers to it first and its recommendation still reads as current.
It didn't misdirect the answers.

### 3. Verification: adequate (covers: computation, for the optimized candidates)

- **The record:** `discover/frontier.json`, 26 scoped instances, with a declared
  `reproduce`.
- **Checks run** (fresh clone of the launch branch, Python 3.14.6, cargo 1.98.1):

  | Command | Result | Time |
  |---|---|---|
  | `python3 scripts/verify.py --output …` (declared) | PASS: 73 matrices, exhaustive 4096-assignment checks where small, negative control | 28 s |
  | `python3 scripts/test_verifier.py` | 9 OK | 0.1 s |
  | `bash scripts/rebuild_check.sh` | 73 matrices rebuilt byte-identical from Rust | 1 min 20 s (cold) |
  | `bash scripts/reproduce.sh replay` (`reproduce_full`, Groth16) | passed | 59 s (warm) |

- **Coverage:** for every optimized candidate the check recounts rows from the committed
  matrices and proves the relation symbolically against a separate specification, and
  the matrices rebuild byte for byte. But ten upstream comparator and full-field
  baseline cases in the record get numerical checks only (the frontier's `scope` says
  so), so the declared check doesn't cover the whole record, and the checker itself is
  unreviewed custom code (assumption `checker-review`, open). Adequate. Strong needs the
  ten cases checked symbolically, or scoped out of the record.
- **Prerequisites:** Python 3.9+ for the saved-artifact check; Rust/Cargo and network
  for the first rebuild; 4 GB RAM; declared in `requirements` (no `os` list).
