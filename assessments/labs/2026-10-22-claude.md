### 1. Orientation: strong

The probe answered all four questions correctly in about 3 minutes, reading `README.md`,
`AGENTS.md`, `DISCOVERY.md`, `PARTICIPATION.md`, the donor-session package's README,
`discover.json`, Discussions #1–#4, `discover/handoff.md`, `discover/messages.jsonl`,
`discover/catalog.json`, `docs/VERIFY.md` and `docs/PUBLICATION.md`.

- **Problem:** for each length N, a ±1 sequence with lower aperiodic energy than the best
  verified published construction; the full sequence is the certificate, integer
  arithmetic throughout.
- **Current result:** a 160-length frontier of literature records (not discoveries of
  this project), author-checked by two separately coded exact checkers; five pending
  record candidates from endpoint edits (N=108, 118, 119, 463, 485), awaiting independent
  arithmetic, provenance and novelty review; nothing accepted beyond the literature.
- **Where help is wanted:** independent review of the five candidates first, then
  structured refinement (50), verification (25), source audit (15), algorithm
  measurement (10); generic random-start search discouraged.
- **How to contribute:** a seeded pick, a claim in Handoffs, the declared checks, a
  result package, one focused PR, and what stays with the maintainer.

Stale or confusing text it noticed, none of which misdirected the answers: the bodies of
`docs/ASSESSMENT.md` and `docs/PUBLICATION.md` still describe the closed pre-launch state
under a launch banner; the first local handoff in `discover/handoff.md` says no
maintainer is assigned; `AGENTS.md` starts agents at the picker, while the review-first
priority is stated only in the catalogue and the handoff, so the default seed drew an
algorithm task.

### 2. Coordination: adequate

- **Spread: adequate.** A seeded, weighted draw over the catalogue (`scripts/pick.py`).
  It surfaces claims from `discover/messages.jsonl` but not the Handoffs thread, so it's
  a draw that ignores live claims (§3.2). Duplicate rate: unknown (no activity).
- **Live state: adequate.** Discussions #1–#4 (Start here, Handoffs, Proposals,
  Feedback) with the protocol's message convention. The two open handoffs are local
  (`discover/handoff.md`, 2026-10-20) and not mirrored in the Handoffs thread.

### 3. Verification: strong (covers: computation)

- **The record:** `discover/frontier.json` (`claim_kind` exact), a table of 160 lengths
  in `data/frontier.json`, each row the minimum energy among imported published
  witnesses, with `reproduce` and `check_row`.
- **Checks run** (fresh clone of `b368052`; Python 3 and a C++17 compiler, no packages):

  | Command | Result | Time |
  |---|---|---|
  | `reproduce`: `import_sources.py --check && check_frontier.py` | PASS: 160 rows, 221 comparison witnesses, sources byte-identical | 13 s |
  | `check_row` on three rows drawn with seed 20261022 (N=459, 517, 109) | PASS each | <1 s each |
  | `make check` (build, unit tests, solver self-test, frontier) | PASS | 5 s |
  | `independent_check.py`, `check_results.py`, `report.py --check` | PASS | seconds |

  The worker agent also ran the full replays (`check_results.py --replay`, 160 runs;
  the donor session's `check.py --replay all`, 136 trajectories, 35 min), the five
  `check_candidate.py` runs and the participation verifier: all PASS.

- **Coverage:** the per-row check recomputes each witness's energy from the full
  sequence and compares it with every imported alternative, which is the whole claim
  as scoped. What it doesn't cover is stated as assumptions in the record, both marked
  partial: completeness of the literature audit, and optimality labels for N≤66 (taken
  from the literature; enumerated here only for N≤16).
- **Packaging:** result packages need `TASK.json`, `VERIFY.json`, hashes, commands and
  all run logs (`docs/VERIFY.md`, `scripts/check_package.py`); the donor-session package
  follows them.
- **Sources:** one stored snapshot wasn't openly licensed (Packebusch and Mertens,
  arXiv:1512.02475, arXiv's non-exclusive license). The launch replaces it with the
  factual table extracted from it (`data/sources/optimal-table.json`), cited by URL,
  access date and SHA-256 with `"stored": false`; the importer's output is identical.
  Other stored papers are CC BY 4.0, and the `git_labs` tables are GPL-2.0.
