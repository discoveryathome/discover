## The gap

The integer-mult-bounds record
([`assessments/integer-mult-bounds/2026-10-17-claude.md`](../../assessments/integer-mult-bounds/2026-10-17-claude.md),
*Doesn't fit the rubric*) grades Review strong on time to first response (0.43 days), but notes that the
project's merges are "archival intake, not acceptance". The project's `CONTRIBUTING.md` says:

> New isolated research packages may be merged after source/integrity intake while remaining
> `partially_reviewed` in the ledger … Such a merge retains the contribution; it does not verify a
> theorem, certify a new κ, or change the selected result.

So the Review axis counts as a response something the project itself says is not review.

## Measurement

- **Sources.** The project's PR ledger (`docs/research/pr-ledger.json` at `20ecf2891d80`, covering PRs up to
  #3528) joined with GitHub PR states. The PR data is the read-only fetch used for #5.
- **Window.** 2026-10-04T16:00Z to 2026-10-18T16:00Z. Every one of the project's PRs falls in it.
- **Raw data.** [`intake-2026-10-18/intake-window.json`](intake-2026-10-18/intake-window.json).

| GitHub state | Ledger disposition | PRs |
|---|---|---:|
| merged | incorporated | 1,688 |
| merged | **partially_reviewed** | **769** |
| closed | incorporated | 376 |
| closed | partially_reviewed / unreviewed / superseded | 16 / 2 / 2 |
| open | partially_reviewed / unreviewed | 117 / 58 |
| not yet in the ledger | — | 335 |

- **31.3% of merged PRs (769 of 2,457) have no recorded review outcome** beyond partial review. Each
  counts as a first response within hours.
- The selected record's newest source PR is **#1094**. Of the 2,274 later PRs, 1,948 have been merged,
  and none has changed the frontier.
- The ledger records dispositions but not dates, so *time to a recorded outcome* can't be measured yet.

The other listed projects show nothing on this gap. applied-butterfly-mult and the hub have no outside
contributions in the window (see #5's report), and neither declares merging as intake.

## What changes

`spec/v0.md` §3.2 Review gets an **Intake is not acceptance** paragraph. Where a project's docs say merges
are intake, the assessment reports two figures next to the grade: the share of merged contributions
without a recorded review outcome, and the date the frontier record last changed.

**No grade changes.** One project with data is not enough to set a cutoff, and the ledger has no dates for
a time-based measure. On these figures, integer-mult-bounds would show *31% of merged contributions have
no recorded review outcome* and *frontier last changed at #1094*, next to its Review grade. The grade
itself is not changed by this proposal.

## Not checked

  outcomes.
- The 335 window PRs newer than the ledger's last reconciliation.
- Whether the date the frontier last changed is a fair stand-in for acceptance throughput.
- Any second project that separates intake from acceptance.
